# 羽球训练家 · 手机助手

安卓 APK，使用手机自身网络打开学校登录页面。现有预约网站嵌在应用中，学校窗口与预约窗口分开。iPhone 暂时使用电脑辅助导入，见下方说明。

## 使用

1. 打开应用，先注册或登录自己的「羽球训练家」网站账号。
2. 点底部 **学校登录**，在学校原网页完成认证并进入预约首页。学校提供的认证方式保持不变。
3. 点 **完成登录**。应用只提取本次学校窗口的 Cookie（含 HttpOnly）、Token、currentUser、User-Agent 和统一认证 Cookie。
4. 点 **填入网站**，检查网站账号，再点网页中的 **验证并保存**。只有服务器验证通过才算连接成功。
5. 后续场地、预约与任务仍使用网站原有流程。提取或填入不会预约、支付，也不会绕过学校账号限制。

学校是否接受 Android WebView 必须实机验证；构建成功、模拟器启动不等于真实学校登录通过。扫码跳转或学校额外验证可能需要使用网页提供的其他登录方式。

## 手机端设计

- 目标：让用户在自己的手机上登录学校，减少手动复制步骤。
- 风格：沿用奶油色、深蓝描边、红色主按钮的像素道馆界面。
- 层级：顶部品牌与状态，中间完整网页，底部三个触控入口。
- 字体：系统中文保证学校表单可读，品牌标签使用等宽字体。
- 交互：加载进度和错误信息始终可见，不增加装饰动画。
- 区别：学校原网页位于独立的本机登录窗口，不把学校密码交给预约服务器。

## 隐私与边界

- 不读取手机 Chrome、Safari 或其他应用的 Cookie。
- 不向页面暴露 JavaScript 原生权限桥；由用户点击原生按钮后定点读取学校页面。
- 只允许 HTTPS 学校认证来源、微信认证来源和固定预约网站；不忽略证书错误。
- 提取结果只暂存在应用内存。复制是独立操作，请勿把会话发送到群聊。
- Android 学校窗口使用独立进程与 WebView 数据目录，开始和结束时清理学校会话；应用备份关闭。
- 退出或进程被系统结束后，未导入的结果需要重新提取。网页账号和已保存的服务器任务独立于学校临时窗口。

## 构建与安装

### Android

Android 9+；JDK 17、Android SDK 35、Gradle 8.11.1。

```sh
cd mobile/android
gradle testDebugUnitTest assembleRelease
```

安装发行 APK 需要设置 `QUEST_KEYSTORE`、`QUEST_KEYSTORE_PASSWORD`；密钥仅放私有目录或 GitHub Actions Secrets，不能提交到仓库。未提供签名时只能产生未签名的 release 包；`assembleDebug` 可用于本地开发。

### iPhone：电脑辅助连接，不需要 Mac

1. 用 **Windows 或 Mac** 打开预约网站，登录自己的羽球训练家账号。
2. 在「登录设置」下载电脑登录提取脚本，在其独立窗口完成学校登录。
3. 将结果粘贴回同一网站账号，点击「验证并保存」。
4. iPhone 用 Safari 打开预约网站，登录 **同一个羽球训练家账号**，即可查询、预约和查看任务；也可在 Safari 分享菜单添加到主屏幕。
5. 电脑不需要为网站上的任务一直开机；任务运行在服务器上。如果学校会话失效且自动续期失败，需再次用电脑导入。

这不是让 Safari 读取电脑 Cookie，而是两个设备使用同一网站账号中的已验证会话。目前没有提供 iOS 安装包；无需 Mac、Apple 开发者账号或安装抓包证书。

工作流 `Build mobile assistants` 手动触发，发布物中不包含学校会话或签名私钥。
