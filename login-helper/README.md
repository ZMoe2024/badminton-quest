# 羽球训练家 · 本地登录提取脚本

当前版本 **v1.1**：修复 v1.0 启动窗口时可能出现的 HTTP 400 白屏。请关闭旧窗口，重新下载并完整解压新版；终端开头应显示 v1.1。已在 Windows Chrome 实测进入学校统一认证页。

不安装浏览器扩展。脚本打开独立的学校登录窗口；你完成一次登录后，自动读取完整 Cookie（含 HttpOnly）、Token、currentUser、浏览器标识，以及本次登录的学校统一认证 Cookie，复制为 JSON。只需回到羽球训练家粘贴并验证。

## 准备

- Windows 10/11，或 macOS 11 及更新版本；装有 Google Chrome 或 Microsoft Edge。
- 从网站「登录设置」下载 ZIP 并**完整解压**，所有文件放在同一文件夹。
- 首次运行自动从 nodejs.org 下载固定版本 Node.js 到个人缓存目录，并核对内置 SHA-256；已有 Node.js 22+ 时直接使用。不需要自己安装 Python、Node.js 或扩展，不修改系统环境变量。

## Windows

1. 双击解压后的 **Start-Windows.cmd**。
2. 等待独立学校登录窗口出现，在该窗口完成扫码、验证码等学校登录操作，直到预约首页正常显示。
3. 终端提示「已提取并复制完整会话」后，回到羽球训练家 → 登录设置，按 Ctrl+V 粘贴 JSON，再点「验证并保存」。

也可在该文件夹打开 PowerShell 运行：

```powershell
.\Start-Windows.cmd
```

启动器只为本次 PowerShell 进程使用脚本执行选项，不永久修改系统策略。若学校或公司设备禁止脚本，请遵守设备策略，不要关闭安全软件。

## macOS（Apple Silicon / Intel）

1. 打开「终端」，输入 `zsh `（末尾有空格）。
2. 把解压后的 **Start-macOS.command** 拖进终端，回车。
3. 在脚本打开的独立学校窗口完成登录，等待终端显示提取完成。
4. 回到羽球训练家 → 登录设置，按 ⌘V 粘贴 JSON，再点「验证并保存」。

或在解压目录运行：

```sh
zsh ./Start-macOS.command
```

macOS 尚需实机验证；已核对 Intel / Apple Silicon 下载包与官方校验值。

## 使用边界与排错

- **先运行脚本，再在它打开的窗口登录**。不是让脚本读取日常浏览器的已有资料；普通浏览器已有的登录不会自动转入这个独立窗口。
- 仅连接本机回环地址的临时浏览器调试端口，不开放远程访问，不降低浏览器沙箱保护。结束后关闭该独立浏览器并删除本次临时资料目录，不修改日常浏览器。
- 默认包含本次学校统一认证 Cookie，以便后端尝试续期。若不想包含，Windows 用 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-Windows.ps1 --no-sso`；Mac 用 `zsh ./Start-macOS.command --no-sso`。
- 学校可能要求每次扫码或验证码，统一认证仍会失效。脚本不会绕过验证，不承诺永久保活。
- 等待最长 10 分钟；按 Ctrl+C 取消。学校返回持续空白的 HTTP 错误页时，脚本会提前退出并显示状态码；不会把这种情况误报为提取成功。出现「未找到浏览器」时先安装 Chrome 或 Edge。
- 自动复制失败时，终端显示完整 JSON 供手动复制。请只复制从 `{` 到 `}` 的内容，不要复制提示语。
- 数据不上传、不写入导出文件、不自动预约或付款；由你手动粘贴到信任的部署。临时浏览器在运行期间会把自身会话写入临时目录，正常结束时清理；进程被强制结束或电脑崩溃时可能需要手动删除系统临时目录中的 `quest-school-login-*`。
- 剪贴板不会自动清空，切勿将会话发到群聊或公开仓库。手机用户可先在电脑连接，再在手机登录同一羽球训练家账号。
- 「已提取」只代表本地读取成功，云端还需向学校验证；不同网络来源的 Cookie 可能被学校防护拒绝，请以网站验证结果为准。

原理依据：[Chrome 对独立调试资料目录的要求](https://developer.chrome.com/blog/remote-debugging-port)。本工具只操作自己创建的临时资料目录。
