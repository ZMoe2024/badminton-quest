# 0.7.2 登录白屏修复

2026-09-18，在相同机器和网络、全新独立浏览器资料下比较：

- 旧 Playwright launch + new_context：预约首页先返回 412，保护脚本加载后返回 400，页面空白；学校认证入口可显示，但返回预约系统的回调同样出现白屏。
- 普通 Chrome 独立进程 + 本机 CDP 连接：预约首页先返回 412，再返回 200；cas.html 返回 200，网站正常跳转学校登录页面。重复观察到该结果。

改动位于 browser_login.py：使用单独临时用户目录启动普通 Chrome，系统未安装时回退到启动器安装的 Chromium；通过仅绑定本机的端口接入，先访问预约首页完成初始化。保持原有凭据验证、账号一致性校验、加密保存与取消逻辑。退出时关闭本次拥有的浏览器并清理其临时目录，不访问日常浏览器资料。

验证结果：

- 104 项离线测试通过。
- 实际 Chrome 中的模拟登录、取消、验证拒绝、HTTP 400 错误显示通过，临时目录清理通过。
- 使用者在新版中完成真实学校登录，程序返回 success；窗口关闭后，Python 从加密保存文件加载的会话再次验证 valid=true，ssoAvailable=true。
- 发布包干净解压、独立虚拟环境依赖安装、界面服务启动及凭据泄漏扫描通过。
- 本次没有提交预约或支付；没有原生 Mac 实测。

证据支持修正浏览器启动和初始化方式；未据此宣称网站所有 HTTP 400 都来自同一原因，也不能保证学校认证 Cookie 永不过期。
